# Schema Comparison: Do the Nine Share a Template?

## The 1000265-269 Tied Set: YES, shared template

All five share the same 4-color palette (W, AB, RL, RB), with minor additions:
- 265: W22, RL15, AB14, RB2, DG1
- 266: W18, AB18, RL17, RB1
- 267: AB21, W20, RB11, RL9
- 268: W24, AB23, RB14, RL10, MB1
- 269: W35, AB35, RL19, RB16

Color roles are consistent: W and AB are the majority colors (data columns),
RL is secondary, RB is minor. The palette is identical across all five.

They are physically tied together (OKR notes: "part of a set of 5 khipu
tied together"). This is a filing cabinet: five documents, one template,
one office.

Twist: S-dominant in 265, 266, 268, 269 (98-100% S). 267 is mixed (46% S,
54% Z) — the exception within the set.

Value scales differ between the five (265 tracks large values, median 343;
269 tracks small values, median 6), suggesting each document covers a
different category or time period within the same format.

## What grouped them together

The clustering was driven by the dense-value statistical profile
(high nonzero rate, information-dense), not by shared template. The nine
are statistically similar (dense values, low structural overhead) but
only five share an actual schema.

## Conclusion

The "9-group" is two things:
1. **A real 5-document set** (1000265-269): shared template, shared palette,
   physically tied, one office. This IS a document type instance.
2. **Four statistical neighbors** (1000344, 1000443, 1000446, 1000608):
   dense values but different templates, different palettes, different
   twist conventions, different provenances.
