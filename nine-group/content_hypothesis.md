# Content Hypothesis: What Are They Tracking?

## Color-value stratification (1000265-269 tied set)

Each color tracks a different value magnitude:

**1000265:**
- W: median 861, max 2716 (large)
- RL: median 380, max 734 (medium)
- AB: median 339, max 756 (medium)
- RB: median 10, max 15 (tiny)

**1000269:**
- W: median 14, max 81 (small-medium)
- AB: median 5, max 36 (small)
- RL: median 3, max 17 (tiny)
- RB: median 4, max 15 (tiny)

The pattern: W = largest values, AB = medium, RL = medium-small, RB = smallest.
This is consistent across the set even as absolute scales differ.

## Interpretation

Different colors tracking different magnitudes suggests different commodities
or categories with naturally different quantities. For example:
- W (large): bulk staples (maize, potatoes) counted in hundreds/thousands
- AB (medium): secondary goods counted in tens/hundreds
- RL (medium-small): smaller-quantity items
- RB (tiny): rare/valuable items counted in single digits

This is the warehouse/inventory pattern, not the census pattern. Census
khipu show demographic categories (age groups, tribute status) with small
numbers. These show magnitude-stratified commodities.

## Hierarchy: header + detail, not aggregation

L1 sums are 4-6x L2 sums. Parents are NOT totals of subsidiaries.
The L1 cords carry large header values; L2 cords carry smaller detail values.
This is a "summary + breakdown" structure, not a "total = sum of parts"
structure.

## The five documents in the tied set

Value scales differ dramatically:
- 265: median 343 (large-scale)
- 266: median 17 (small-scale)
- 267: median 16 (small-scale)
- 268: median 27 (medium-scale)
- 269: median 6 (small-scale)

Same template, different scales. Likely: same office, same format,
different commodities, different time periods, or different sub-units.
Like five spreadsheets from the same department covering different
product lines.

## 1000344: the table

323 cords, all L1, no hierarchy. The Ascher notes describe 25 groups of
15 pendants arranged as a rectangular table. This is a flat data table,
not a hierarchical document. Values mostly 11-100 (174 cords), some larger.
Different palette (MB, BY, W, BL). Likely a different office, different
format, but same "dense data table" statistical profile that caused the
clustering.

## 1000608: the aji khipu

"Khipu del Aji" — chili pepper khipu from Incahuasi. Only 2 colors (W, AB).
41% zeros. This is likely a single-commodity inventory (chili peppers),
which explains the minimal palette. Not the same type as the tied set.

## Summary hypothesis

The tied set (1000265-269) is a **multi-commodity inventory**: five documents
from one office, same template, tracking different goods at different scales.
The color stratification by magnitude is the signature of commodity inventory,
not census.

The other four are independent dense-value documents of different types.
