# Wrapping-as-Ownership Hypothesis: Test Results

**Hypothesis (Charles):** On two-color cords, the outer/dominant color conveys ownership and the inner/secondary color conveys the object.

**Verdict: NOT SUPPORTED.** Two-color cords show no systematic ownership code and no distinctive knotting.

---

## Critical Caveat: What "Two-Color" Means in the Data

The Ascher color coding has **no wrapping/sheathing operator**. Two-color cords use:
- `:` = mottled (fibers of two colors spun together) — 24.7% of all cords corpus-wide
- `-` = barber pole (two colors twisted together)
- `%`, `*` = special operators

There is no code for one color sheathing another. This analysis treats COLOR_CD_1 as dominant/outer and COLOR_CD_2 as secondary/inner, but the physical reality is mixed fibers, not wrapping. The hypothesis as literally stated (wrapping = ownership) **cannot be tested** with this data — there is no wrapping variable.

---

## Test 1: Same Core, Different "Wrappings" (Same Good, Different Owners?)

**Result: Massive mixing, no code.**

| Inner (CD_2) | Distinct outers | Cords |
|---|---|---|
| W (white) | 59 | 5,555 |
| AB (light brown) | 37 | 1,715 |
| MB (med brown) | 32 | 998 |
| KB (dark brown) | 17 | 247 |

White as the secondary color pairs with **59 different dominant colors**. If the outer color were an ownership label, this would mean 59 different owners all recording white-core goods — possible but the mixing is so complete it shows no clustering or structure.

## Test 2: Same "Wrapping," Different Cores (Same Owner, Different Goods?)

**Result: Massive mixing, no code.**

| Outer (CD_1) | Distinct inners | Cords |
|---|---|---|
| MB (med brown) | 36 | 2,045 |
| AB (light brown) | 31 | 1,782 |
| KB (dark brown) | 22 | 1,541 |
| W (white) | 30 | 831 |

Same conclusion. The combinatorial space is nearly fully explored — this is production noise, not a code.

## Test 3: Inkawasi Peanut Quipu

Two-color rates: 1000607 (18%), 1000610 (30%), 1000611 (12%), 1000612 (7%), 1000614 (19%).

Dominant patterns are W:MB, MB:W, NB:W — all within the coastal brown/white family. The two-color cords use the **same palette family** as the single-color cords on the same quipu. No wrapping color introduces a new ecological signal.

W:MB vs MB:W ordering shows no positional pattern (CORD_ORDINAL data unreliable for Inkawasi).

## Test 4: Santa Census Quipu

Santa has the highest two-color rate among major sites (36.8%). But wrapped cords do not align with 6-block positions or moiety (recto/verso) in any detectable pattern. The two-color cords appear to be part of the name-color lookup, not a separate ownership layer.

## Test 5: Highland "Wrapping" on Coastal Core

GG:W appears on 247 cords across 65 quipu; BL:W on 91 cords across 17 quipu. These are scattered, not concentrated. No site or quipu uses highland-dominant wrapping systematically on coastal-secondary cords as an ownership mark.

---

## Additional Question: Do Wrapped Cords Have Distinctive Knotting?

**Answer: No.** If wrapping were an ownership seal, the knots might carry a signature. They don't.

### Knot type distribution: two-color vs single-color

| Type | Two-color | Single-color |
|---|---|---|
| S | 68.6% | 67.4% |
| L | 22.0% | 24.5% |
| E | 8.0% | 7.5% |
| SP | 0.37% | 0.18% |
| TF | 0.11% | 0.12% |
| EE | 0.10% | 0.06% |

Nearly identical. Rare types are marginally enriched on two-color cords but absolute numbers are tiny and scattered across many color combos (no clustering).

### Knot types exclusive to wrapped cords

**None.** The alphabets are identical. Every knot type appears on both.

### S/Z direction ratios

Two-color: 31.0% S. Single-color: 32.9% S. No difference.

### Knots per cord

Two-color: 2.81. Single-color: 3.01. No meaningful difference.

### The bean quipu SP anomaly

The 8 spiral knots on the strong-red cord (1000613) — the most anomalous knot feature in the commodity set — are on a **single-color** cord (0R), not a wrapped cord. The signature-like knotting, where it exists, is not on two-color cords.

---

## Conclusion

1. **The hypothesis cannot be literally tested** — the database has no wrapping variable, only mottled/twisted two-color codes.
2. **As a dominant/secondary color code, it fails** — the mixing is too complete (59 outers per inner, 36 inners per outer) for a systematic ownership system.
3. **Wrapped cords have no distinctive knotting** — same alphabet, same S/Z ratios, same knot density. No signature, no seal.
4. **The most anomalous knotting** (bean quipu SP cluster) is on a single-color cord.

**Best explanation:** Two-color cords reflect fiber supply and spinning practice — what colors of thread were available when the cord was made. The site-level variation (15–48%) supports production/institutional differences, not a semantic code.

**What would change this:** If future recording distinguishes actual wrapping (sheathing) from mottling, the hypothesis could be retested. The current data cannot address it.
