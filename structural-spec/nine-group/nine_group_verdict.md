# Verdict: Is the 9-Group a Document Type?

## Short answer: No. But it contains one.

The nine do not share a template. They share a statistical profile
(dense values, low structural overhead) that caused the clustering
algorithm to group them. Only five share an actual schema.

## What the nine really are

### A real document set: 1000265-269 (5 khipu)

**Verdict: YES, coherent group.**

- Shared 4-color palette (W, AB, RL, RB) in consistent roles
- Physically tied together (filing cabinet)
- Same museum, sequential IDs, examined together
- S-twist dominant (4 of 5)
- Low zero rates (4-7%)
- Color-value stratification (each color tracks a different magnitude)

This is five documents from one office using one template. The template
is a **multi-commodity inventory**: different colors for different goods,
values stratified by commodity scale, header+detail hierarchy.

**Proposed name:** "Tied inventory set" or "multi-commodity inventory format."

The S-twist suggests south coast origin (moderate confidence). The
"waterfall khipu" nickname and Banco Central holding are the only
provenance clues.

### Four statistical neighbors: NOT the same type

- **1000344:** Different palette, mixed twist, flat table structure (323
  cords, all L1). A dense data table, but a different format from a
  different office. The Ascher notes' "rectangular table" description
  confirms tabular structure.
- **1000443:** 8-cord stub from Pachacamac. Too small to type.
- **1000446:** 6-color palette from Pachacamac, Z-twist, very large values
  (max 39,263). Different format, different office.
- **1000608:** 2-color "aji" khipu from Incahuasi, Z-twist. Single-commodity
  inventory (chili peppers). Minimal palette reflects minimal commodities.

## Criteria assessment

| Criterion | 5-set | All 9 |
|---|---|---|
| Shared schema (colors in same roles) | YES | NO |
| Shared value profile | YES (stratified) | PARTIAL (dense, but different scales) |
| Coherent provenance | LIKELY (one office) | NO (3+ provenances) |
| Physical association | YES (tied) | NO |

## What we learned

1. **The clustering was right to flag these**, but the group is heterogeneous.
   Statistical similarity ≠ shared template.

2. **The real discovery is the tied set.** Five khipu, one template, tied
   together — this is a filing cabinet with a consistent inventory format.
   It deserves its own document type designation.

3. **Dense-value is a useful statistical flag** but not a type definition.
   It identifies khipu worth investigating, but the schema comparison is
   what determines typehood.

4. **The S-twist → south coast hypothesis is weakened.** Two Pachacamac
   khipu (central coast) and one Incahuasi khipu (south-central) in the
   9-group are Z-dominant. Twist may be office-specific rather than
   purely regional.

## Recommended next steps

1. Designate 1000265-269 as a typed set: "tied multi-commodity inventory."
2. Investigate Banco Central acquisition records for provenance.
3. Compare the tied-set template against known warehouse/inventory khipu
   to determine if it's a regional variant of the warehouse format or
   a distinct type.
4. The remaining ~40 true unknowns in the residuals should be checked
   for similar tied-set structures (physical association as a grouping
   criterion, not just statistics).
