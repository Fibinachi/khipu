# Nine-Group Investigation: Executive Summary

**Date:** 2026-10-11
**Question:** Is the 9-group dense-value cluster a document type?
**Answer:** No — but it contains a real 5-document set that is.

## The Nine

1000265, 1000266, 1000267, 1000268, 1000269, 1000344, 1000443, 1000446, 1000608

## Key Finding

The nine do **not** share a spreadsheet template. Only five do:

**1000265-269: a tied inventory set (REAL)**
- Five khipu physically tied together at Banco Central de la Reserva
- Shared 4-color palette (W, AB, RL, RB) in consistent structural roles
- S-twist dominant, 4-7% zero rates
- Color-value stratification: each color tracks a different magnitude
  (W = large, AB = medium, RL = small, RB = tiny)
- Different value scales per document (same template, different goods)
- **Interpretation:** multi-commodity inventory from one office

**The other four: statistical neighbors, not the same type**
- 1000344 (Paris): different palette, flat 323-cord table, mixed twist
- 1000443 (Pachacamac): 8-cord stub, too small to type
- 1000446 (Pachacamac): 6 colors, Z-twist, very large values
- 1000608 (Incahuasi): 2-color chili-pepper inventory, Z-twist

## Provenance

- Tied set: unknown (Banco Central, no excavation context). S-twist
  suggests south coast (moderate confidence).
- 1000443/1000446: Pachacamac (central coast)
- 1000608: Incahuasi ("Khipu del Aji")
- The S-twist → south coast hypothesis is weakened by Pachacamac and
  Incahuasi pieces using Z-twist. Twist may be office-specific.

## Implications

1. Statistical clustering identifies candidates; schema comparison determines types.
2. Physical association (tied khipu) is a stronger grouping criterion than statistics.
3. The tied set deserves its own type designation: multi-commodity inventory.
4. ~40 true unknowns remain in the residuals.
